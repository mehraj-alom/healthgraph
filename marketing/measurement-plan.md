# HealthGraph — Measurement & Rank Tracking Plan

## Phase 1: Technical Setup (Week 1)
- [ ] Plausible Analytics (cookieless, DSGVO-clean) — install on healthgraph.shop
- [ ] Google Search Console — verify ownership, submit sitemap.xml
- [ ] Google Analytics 4 (optional, if needed for App Store funnel)

## Phase 2: Keyword Tracking (Week 1-2)
- [ ] Set up rank tracking for 50+ German health keywords
- [ ] Baseline: current positions (mostly unranked)

### Target Keywords (50+)
**Symptome:** muedigkeit ursachen, 14 uhr loch, ständige muedigkeit, schlafstoerungen, stressbewaeltigung
**Medikamente:** medikamente einnahme, medikamente richtig einnehmen, schilddrüsenunterfunktion, vitamin d mangel, b12 mangel
**Datenkontrolle:** dsgvo gesundheitsdaten, gesundheitsdaten löschung, datenschutz gesundheitsapp, datenauskunft
**Prävention:** herz-kreislauf, immunsystem staerken, check-up, gesundheit im alter, blutzucker senken
**Alltag:** arzttermin vorbereiten, gesundheitstagebuch, elektrolyte
**Product:** gesundheitsapp, gesundheit tracken, health graph

## Phase 3: Weekly Review (Every Monday)
- [ ] Search Console: impressions, clicks, CTR, average position
- [ ] Plausible: page views, traffic sources, conversions
- [ ] Rank tracking: position changes for target keywords
- [ ] Content gaps: queries with impressions but no clicks

## Phase 4: Content Iteration (Monthly)
- [ ] Update articles based on GSC query data
- [ ] Add new content for high-impression keywords
- [ ] Improve internal linking based on crawl data
- [ ] A/B test meta descriptions for CTR improvement

## KPIs (3-month targets)
- [ ] 100+ indexed pages
- [ ] 1,000+ monthly organic visits
- [ ] Top 10 for 5+ health keywords
- [ ] 3+ AI citations (ChatGPT, Perplexity)
- [ ] 5+ referring domains
